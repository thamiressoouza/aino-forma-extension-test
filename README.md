
# Urban Analysis Viewer — Folium Preview + Forma Canvas Overlay

This repository hosts the Folium preview generated by the AINO → Forma middleware.

Files:
- `index.html`: Folium preview with an injected button for Forma canvas overlay.
- `canvas_layers.js`: processed GeoJSON layers used by the overlay button.

The Forma canvas overlay is temporary and uses the Forma render API.
The consultable attributes remain available in the Folium preview popups.

Do not upload confidential project, client, or company data to this public repository.
